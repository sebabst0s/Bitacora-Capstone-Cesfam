# Bitacora semana 3

## 1. ¿Qué está ocurriendo?
El sistema actual de reagendamiento de horas médicas en el CESFAM Providencia se coordina de forma manual, mediante contacto telefónico entre el personal administrativo y el paciente. Este proceso no está automatizado ni digitalizado.

## 2. ¿A quién le ocurre?
Afecta principalmente al **personal administrativo** del CESFAM, quienes deben destinar tiempo a coordinar telefónicamente cada reagendamiento, y de forma indirecta a los **pacientes**, que dependen de este proceso poco eficiente para acceder a sus horas médicas.

## 3. ¿Por qué importa?
- Genera una **carga de trabajo innecesaria** para el personal administrativo.
- Produce **mayor estrés** y frustración en los funcionarios encargados.
- Se traduce en **poca motivación** para realizar las labores diarias, afectando la productividad general del centro de salud.

## 4. ¿Qué sabemos?
1. El sistema actual funciona mediante coordinación telefónica con el paciente.
2. No existe un sistema digital de reagendamiento automatizado.
3. Los actores principales son el personal administrativo, los pacientes y el personal clínico.
4. El reagendamiento demanda una cantidad significativa de tiempo del personal.
5. El personal administrativo siente frustración por no poder usar ese tiempo en tareas más productivas.
6. Existen quejas recurrentes sobre el sistema de reagendamiento actual.


## 5. ¿Qué creemos pero aún no sabemos?
1. Creemos que un sistema automatizado de recordatorios y reagendamiento reduciría significativamente las inasistencias, pero no tenemos aún el dato cuantitativo que lo confirme.
2. Creemos que los pacientes estarían dispuestos a usar un canal digital (WhatsApp, SMS, etc.) para reagendar, pero no hemos validado esta preferencia directamente con ellos.
3. Creemos que Power Automate será suficiente para prototipar la solución sin incurrir en costos de licencia, pero aún no hemos confirmado sus limitaciones técnicas reales en este contexto.

## 6. ¿Qué necesitan averiguar y todavía no saben?
1. ¿Cuál es la tasa actual de inasistencias (no show) en el CESFAM Providencia y cuántas horas de personal se pierden semanalmente en reagendamiento?
2. ¿Qué canal de comunicación prefieren realmente los pacientes para gestionar sus citas (llamada, WhatsApp, SMS, correo)?
3. ¿Qué limitaciones técnicas y de licenciamiento tiene realmente Power Automate para conectarse con WhatsApp/SMS sin costo?
4. ¿Qué datos o sistemas existentes (si los hay) podemos usar como fuente para alimentar el prototipo sin conectarnos a sistemas clínicos reales?
